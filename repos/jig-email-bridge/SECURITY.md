# Security Policy

## Supported Versions

All versions are pre-release: expect frequent breaking changes until we hit 0.1.0 and first end-user contact. Backwards compatibility is not guaranteed pre-0.1.0 release.

| Version | Supported          |
| ------- | ------------------ |
| 0.0.1   | :white_check_mark: |

## Reporting a Vulnerability

Contact security@gigue.ai // #alert-security for any issues. When OSS released, open security alerts will follow.

Do _not_ send 1:1 DMs or emails to your favorite engineer - these negatively impact our SLAs and prevent resolution.

Do _not_ open tickets or start work without coordinating with security engg first.
