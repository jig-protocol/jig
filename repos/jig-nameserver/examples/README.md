# Jig Nameserver Examples

Example config files. A unit test parses each one strictly, so they stay loadable.

- `config/profile_potato.toml` – minimal single-node deployment with a high-sec ruleset.
- `config/profile_federated.toml` – multi-ruleset config showing cross-translation contracts.

- `admission_flood.rs` – bot-flood benchmark of the registration pool and proof-of-work market; see `docs/investigations/2026-10-25-admission-flood.md`.
