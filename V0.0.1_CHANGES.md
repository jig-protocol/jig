# v0.0.1 Changes

## Secrets

- **jig-nameserver/src/config.rs**: `default_server_secret()` now panics with a clear message if `JIG_NS_SECRET` env var is not set (previously silently fell back to `"dev-secret"`).
- **repos/.env.example**: Created — documents all required env vars, especially `JIG_NS_SECRET`.
- **Note**: Two `"dev-secret"` usages in `server.rs` lines ~1945/2049 are inside `#[cfg(test)]` and are intentional test fixtures; left unchanged.

## Unimplemented Panics

- **jig-nameserver/src/analytics/mod.rs** (`tier2::export_parquet`): Replaced `unimplemented!()` with `eprintln!` warning + `Err(...)` return.
- **jig-nameserver/src/analytics/mod.rs** (`tier3::stream_to_clickhouse`): Same treatment.

## Silent CLI No-ops (4 commands)

All four stub commands in `jig-cli/src/main.rs` now exit with code 1 and a clear error message instead of silently returning `Ok(())`:
- `jig block lint` — not yet implemented (waiting for jig-core Wasm validation API)
- `jig block sign` — not yet implemented (waiting for jig-core Ed25519 signing API)
- `jig block verify` — not yet implemented (waiting for jig-core Ed25519 verification API)
- `jig block capabilities` — not yet implemented (waiting for jig-core capability DSL)

## Test Fixtures

- **jig-nameserver/src/config.rs** (`default_config_is_sane`, `compute_pow_respects_bounds`): Added `std::env::set_var("JIG_NS_SECRET", "test-secret-for-unit-tests")` so tests pass without a real env var.

## Install Script

- **install.sh**: Created at repo root. Builds `jig-server` from source, checks for `JIG_NS_SECRET`, and starts the server. Executable.

## Build

- `cargo build --workspace` passes cleanly (warnings only, no errors).
- `jig-server` starts and listens on `http://127.0.0.1:7117` (confirmed with `timeout 4` test run).

## Versions

- `jig-core`: already `0.0.1` ✓
- `jig-server`: already `0.0.1` ✓
