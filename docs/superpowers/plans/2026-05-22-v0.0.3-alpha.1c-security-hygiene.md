## Phase 1 — Server/pipeline security (#2, #3, #4, #7)

### Task 1.1 — #2: Verify sender_sig on inbound peer blocks

**File:** `repos/jig-server/src/v0_0_2_federation.rs`

**Spec:** Federated blocks currently store `sender_sig: vec![]` and `is_synthetic: false`, bypassing `verify_sig`. Add re-verification.

- [ ] **Step 1: Failing test** in `repos/integration-tests/tests/h3_federation.rs`:

```rust
#[tokio::test]
async fn federated_block_with_forged_author_did_is_rejected() {
    let ns = TestNameserver::start().await.unwrap();
    let srv_a = TestJigServer::start_with_nameserver(&ns, "a.jig").await.unwrap();
    let srv_b = TestJigServer::start_with_nameserver(&ns, "b.jig").await.unwrap();
    srv_a.add_peer(&srv_b).await.unwrap();
    tokio::time::sleep(Duration::from_millis(500)).await;

    // Peer A relays a bundle authored by peer A but with manifest.sender_did
    // pointing at peer B (forged). Peer B's server must reject.
    let alice = Identity::generate();
    let bob_did = "did:jig:zForgedBob";
    let bundle = build_forged_block(&alice, bob_did, "#hello", "I am bob");

    let cid_resp = srv_a.submit_via_admin(&bundle).await;
    // srv_a accepts (sig matches alice's pubkey); but when it relays, srv_b
    // must reject because the bundle's claimed sender_did doesn't match the
    // sig's public key.
    tokio::time::sleep(Duration::from_millis(500)).await;
    let blocks_b = srv_b.list_blocks().await.unwrap();
    assert!(!blocks_b.iter().any(|b| b.cid == cid_resp.cid),
        "srv_b must reject relayed block with forged sender_did");
}
```

- [ ] **Step 2: Implement** — in `ingest_peer_block` (around line 179-235), reconstruct the canonical bundle bytes from the inbound frame, verify the signature against the manifest's claimed `sender_did`, reject on mismatch.

The wire format must carry the sig. Check `Frame::Block` in `repos/jig-pipeline/src/envelope.rs`; if `sender_sig` isn't on the frame, add it. (The locked spec lists this as a "Known seam: Envelope `Frame::Block` carries `sender_sig`" — verify and add if missing.)

- [ ] **Step 3: Add `naively_trust_peer_authored_blocks` antipattern flag** in `jig-config::v0_0_2_server::FederationSection`. When true, skip the new sig check. Surface in `unsafe_options_active()`.

- [ ] **Step 4: Verify test passes**. Commit.

fn load_or_generate_rejects_world_readable_keyfile() {
    let dir = tempdir().unwrap();

    // Create + chmod world-readable
